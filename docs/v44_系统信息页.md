# v44「系统信息」页（主菜单第三项）

日期：2026-10-26

## 1. 问题

v43 的主菜单第三项虽然已经改名为「系统」，但 `menu_ctrl` 仍保留 v31 的
「第三项 = 离开主菜单并启动轮播」逻辑：

```verilog
menu_active <= 1'b0;
wheel_pulse <= 1'b1;
```

同时顶层只在 `menu_wheel && menu_active` 时置 `sys_active`，而 `menu_active`
在同一拍已经被清 0，所以系统页永远打不开。板上的实际表现就是：
点「系统」→ 进入轮播/图片页，再按 Enter 又会弹出设置面板。

## 2. 现在的行为

| 操作 | 结果 |
|---|---|
| 主菜单 W/S 选到「系统」，Enter | 打开「系统信息」层；主菜单保持在底下（压暗 50%），不离开主界面 |
| 系统页打开时 W/S | 被 `sys_on` 冻结，背景菜单选中项不动 |
| 系统页打开时 Enter / Q | 关闭，回到主菜单（不会误触菜单项） |
| 从目录/图片/设置页 | 无法打开（`open_sysinfo` 只在 `menu_active` 时有效） |
| 设置页第 5 行「轮播」Enter | 仍然照旧切换自动轮播；系统页不再顺带启动轮播 |

## 3. 版面

与 `settings_panel` 同一套视觉：深色卡片 `#171B22` + 紫色描边 `#6E5FD8`
+ 金色标题 `#F0CB4D` + 6 行「2 字标签 + 值」，标签 x=122、值 x=260、
行距 40、字段框 252..524。背景不铺黑，只把主菜单压暗 50%。

| 行 | 标签 | 值 | 说明 |
|---|---|---|---|
| 0 | 器件 | `EG4S20BG256` | 安路 EG4S20BG256 |
| 1 | 输出 | `640X480P60` | HDMI 1.4b，640×480p60 |
| 2 | 音频 | `48KHZ WAV` | TF 卡 WAV，48 kHz |
| 3 | 存储 | `TF CARD OK/ERR` | 由 `boot_ok` 实时给出 |
| 4 | 资源 | `LUT17K BRAM54` | 本版 P&R 约 17.4K LUT / 54 BRAM |
| 5 | 版本 | `V44 20261026` | 本版标识 |

## 4. 资源做法

- 系统页与 `settings_panel` **共用** `u_set_font`（两者永不同屏）⇒ **0 BRAM**；
- 不新增 BRAM、不新增 DSP；
- 文字查表用一条 7 bit 扁平 `case`（`{行号, 列号}`），比“每行一套 16:1 mux”省 LUT；
- 版面只画矩形/直线，无乘法器、无除法器、无行缓存；
- 新增的 13 个汉字写进主字库 `font_rom.hex` 的 `0x10..0x1C` 槽（原来只被旧
  sysinfo 使用，且 `0x1A..0x1C` 本来就是空槽），字库仍在 4096 行以内 ⇒
  TD 仍按 8 块 BRAM 实现，**不增加 BRAM**。

## 5. 改动文件

| 文件 | 改动 |
|---|---|

| `rtl/top_tf_hdmi_audio.v` | `sys_active` 改由 `menu_open_sysinfo && menu_active` 打开；Enter/Q 关闭；去掉旧 sysinfo 的动态输入 |

| BRAM / DSP | 54 / 20 | **54 / 20** |

| Setup / Hold | +103 / +25 ps | **+1204 / +21 ps**（0 FEPS，seed 3） |
| bitstream | `…_v43.bit` | **`bitstream/HDMI2_HDMI14_Player_v44.bit`** |
| MD5 | — | **97949274877A2E37651025E1BC7C2EFC** |

mslices 少约 27。已用 `program_spi` 固化到配置 FLASH。
