## 1 需求与实现

### 1.1 主界面 / 图片页左右各一条白色竖线（对称），目录页不加

**实现**：在最终 RGB 输出级加一层“边缘覆盖”，不碰任何 OSD 模块：

```verilog
localparam [23:0] C_EDGE = 24'hFFFFFF;
wire edge_on = ~dir_active;                                   // 目录页直通，不加线
wire edge_px = (osd_x <= 12'd1) || (osd_x >= 12'd638);        // 左右各 2 px
assign vout_data = (edge_on && edge_px) ? C_EDGE : vout_data_sys;
```

要点：

- 左边那条**本来就是** OSD 比 DE 晚 D 拍留下的残影（颜色≈上一行右端那几个像素，
  D 在图片页≈2、菜单页≈4，所以宽度会变）。现在把 `osd_x<=1` 直接覆盖成纯白，
  颜色和宽度都固定下来；
- 右边 `osd_x>=638` 涂白之后，下一行行首的残影会把这根白线“印”回左侧，
  两条线天然对称、等宽（残影机制从“缺陷”变成了“镜像”）；
- `osd_x` 是随 `de` 走的像素计数器，所以覆盖位置就是屏上真实的 x=0..1 / 638..639；
- 目录页 `dir_active=1` 时整层直通，版式保持原样。

**字库怎么解决（关键）**

- 原来 `font_rom_ext` 是 1024 深 = **64 槽**，已被字幕+目录占掉 63 个，只剩 1 个空位；
- 本次新增 54 个汉字（unique 121 字，其中 4 个可从主字库复用），必须扩容：
  **1024 → 2048（64 → 128 槽）**；
- 扩容会多 2 块 BRAM，但这一片 ROM 原来被实例化了**两份**（字幕一份、目录一份，各 2 块），
  这次把它搬到顶层做成**一份共用**（目录页与字幕永不同屏，和 `u_shared_font` 同一个套路）：
  `2 份 × 2 块 = 4 块` → `1 份 × 4 块 = 4 块`，**BRAM 总数不变（59/64）**；
- 字符码 0x100..0x174 连续分配，**原有 63 个字的码值一个没变**（`subtitle_params.vh`
  与 `directory_params.vh` 前 20 行与改前逐字节相同），所以字幕、目录行、底栏展区名全部不受影响；
- 工具链：`tools/make_subtitle_font.py`（EXT_DEPTH 1024→2048、上限 64→128、新增 DIR_ZONE 文案）
  一次生成 `font_rom_ext.hex` + 两份 `.vh` + 字表 + 预览图；
  另加 `tools/preview_directory_v79.py`，把 RTL 的 y 坐标/文案/字模重放成 PNG，
  离线检查换行、边距、有没有压到边框。

## 2 资源与时序（P&R 口径）

| 项 | v79 | **v79b** |
|---|---|---|
| mslices（上限 4900） | 4443（90.67%） | **4535（92.54%）** |
| 综合 LUT / REG | 8344 / 6451 | **8654 / 6452** |
| BRAM9K / DSP | 59 / 20 | **59 / 20（不变）** |
| Setup WNS / TNS | +241 ps / 0 | **+230 ps / 0（0 违例端点）** |
| Hold WNS / TNS | +27 ps / 0 | **+25 ps / 0（0 违例端点）** |
| place seed | 3 | **5** |

- 增量：+26 综合 slice / +92 P&R slice，全部来自目录页那三行的取字/选行逻辑
  （3 组 144 bit 的 4 选 1 + 3 个 9 bit 变址），BRAM 与 DSP 都没动；
- 分时钟余量：`video_clk` **+4.31 ns**、`ext_mem_clk` **+0.40 ns**、`hdmi_5x_clk` +6.0 ns、
  `sd_card_clk` **+0.23 ns**（全局瓶颈，`source_done_seen → bmp_read` 地址使能，
  14 级逻辑 + 4 个加法器，与本次显示层改动无关）；
- **place seed 5 是实测最好的**：同一网表 seed 3 为 +129 ps、seed 2 为 +206 ps、seed 5 为 **+230 ps**；
  seed 4（v79 时试过）会出负 slack。重编请用 5，并确认 `NUM_FEPS=0`。

## 5 备注 / 风险

1. 左侧白线仍是“残影 + 显式覆盖”的组合：若以后改 `de`/OSD 时序（让 OSD 计数提前 D 拍），
   残影消失后左边那 2 px 仍会由覆盖逻辑画出，版式不变。
2. 目录页不加线是硬编码 `~dir_active`；若以后新增全屏页面，需要一并考虑这个条件。
3. 新增的 54 个字只进了 `font_rom_ext`，主字库 `font_rom` / 系统页字库 `font_rom_sys` 未动。
