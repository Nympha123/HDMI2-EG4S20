# v67 系统信息中文滚动页

日期：2026-10-26

## 需求

系统页只说明“博物馆智能展讲系统”的亮点/加分点和三条关键参数，
其他参数（HDMI 版本、TF 文件系统、UI、版本号等）不要；用 Up/Down 滚动。

## 内容

9 行，一次显示 7 行，Up/Down 移动选中行、窗口自动滚动：

| 行 | 内容 |
|---|---|
| 0 | 博物馆智能展讲 |
| 1 | 亮点/加分点 |
| 2 | 4 个展区 A/B/C/D |
| 3 | 主菜单+各展区不同音乐 |
| 4 | 曾侯乙 图5/6 缩放适配 |
| 5 | 音频波形可视化 |
| 6 | 640X480P60 RGB |
| 7 | 48KHZ 16BIT WAV |
| 8 | LUT17K BRAM54 |

- 选中行紫色背景 + 左侧金色竖条，文字白色；未选中青色。
- 底部 `UP/DOWN:SCROLL  BACK:EXIT`；Back 退出，离开主菜单强制关闭。
- 标题仍是「系统信息」，主字库；正文 35 个中文使用独立小字库。

## 字库

- 正文中文：`rtl/font_rom_sys.hex`，576x16（35 个字 + 余量），
  编码 0x80..0xA2；`font_rom_sys` 模块在 `sysinfo_panel.v` 末尾，**2 块 BRAM**。
- 不改 `font_rom_ext` 的 64 个槽，不影响滚动字幕/目录页/展区徽标。
- 标题「系统信息」和 ASCII 仍用主字库 `font_rom`，与 settings 共用。

## 按键

- 主菜单第三项「系统」进入；
- **Up/Down**：选中行上下移动，7 行窗口自动滚动；
- **Back**：退出；
- Enter 在系统页不动作，避免和 v65 的两页翻页混淆。
