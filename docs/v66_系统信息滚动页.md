# v66 系统信息滚动说明页

日期：2026-10-26

## 需求

v65 的 1/2、2/2 两页在板测时容易被误认为“两页一样”，而且只列参数，
没有把项目的亮点/加分点讲出来。改成 **Up/Down 滚动的说明页**，内容覆盖：

- 4 个展区 A/B/C/D；
- 主菜单 + 4 个展区共 5 首不同音乐；
- 曾侯乙展区 A05/A06 的图片缩放适配；
- 音频波形可视化；
- 16 张图片 / 自动轮播；
- 640X480P60 RGB、WAV 48K 16BIT、LUT17K BRAM54 等关键参数。

## 版面

- 14 行，一次显示 7 行；Up/Down 移动选中行，窗口自动滚动。
- 选中行紫色背景 + 左侧金色竖条，文字白色；未选中行青色。
- 底部：`UP/DOWN:SCROLL  BACK:EXIT`；Back 关闭，离开主菜单强制关闭。
- 标题仍是「系统信息」，复用 `font_rom` 现有中文/ASCII，**0 新增 BRAM**。

14 行内容：

| 行 | 内容 |
|---|---|
| 0 | `BONUS: 4 ZONES A/B/C/D` |
| 1 | `BONUS: 5 MUSIC TRACKS` |
| 2 | `ZONE A: ZENG HOU YI` |
| 3 | `BONUS: A05/A06 SCALE` |
| 4 | `BONUS: AUDIO WAVE OSD` |
| 5 | `音频 WAV 48K 16BIT` |
| 6 | `IMG: 16 / AUTO TOUR` |
| 7 | `UI: MENU/DIR/SET/SYS` |
| 8 | `输出 640X480P60 RGB` |
| 9 | `资源 LUT17K BRAM54` |
| 10 | `存储 TF FAT32 FRAG` |
| 11 | `HDMI 1.4B 25MHZ` |
| 12 | `版本 V65 20261026` |
| 13 | `BACK: EXIT` |

> 版本行写的是 `V65 20261026`（沿用 v65 的基线字符串）；当前构建是 v66。
> 要改成 `V66` 只需改一个字符，但需要再综合一次，本版先保持基线。

## 资源/时序

| 项 | v65 | **v66** |
|---|---|---|
| LUT / REG | 17 299 / 6 346 | **17 628 / 6 362** |
| BRAM / DSP | 54 / 20 | **54 / 20** |
| mslices | 4 595 / 4 900 | **4 661 / 4 900（95.1%）** |
| Setup / Hold | +350 / +25 ps | **+952 / +33 ps**（0 FEPS，seed 3） |
| bit / MD5 | `…_v65.bit` / `C451FF22…` | **`…_v66.bit` / `2096F542…`** |

比 v65 多 **66 mslices / 329 LUT**，BRAM 不变；只剩约 239 mslices，
后续不建议再加显示逻辑。已 `program_spi` 固化。

## 按键

- 主菜单第三项「系统」进入；
- **Up/Down**：移动选中行，7 行窗口自动滚动；
- **Back**：退出；离开主菜单也会强制关闭；
- Enter 在系统页不再翻页（避免和 v65 的两页操作混淆）。
