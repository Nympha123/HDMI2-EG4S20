# v54 左边缘竖线修复（当前定版）

日期：2026-10-26

## 1. 现象

- 图片页最左侧：1~2 px 黑竖线；
- 目录页最左侧：同样黑线；
- 主菜单：没有黑线。

后来尝试把消隐数据换成页面底色/上一拍，黑线变成白线，且会遮住字幕左端；
再换成“按页面上边缘色补 x<8”仍会留下白线。

## 2. 根因

`rtl/SD/video_delay.v`：

```verilog
always@(posedge video_clk or posedge rst)
begin
    if(rst) vout_data_r <= 0;
    else if(de_d[19]) vout_data_r <= read_data;
    else vout_data_r <= 0;          // ← 行消隐清零
end
```

`de_r = de_d[20]` 比数据晚一拍，所以每行**第一个有效像素**输出的是这个 0。
图片/目录的 OSD 流水再把这个 0（或后来替换的白）带到左边，形成竖线。
主菜单本身满幅不透明，所以原来没有黑线；换成固定浅色后反而出现白线。

## 3. v54 改法

```verilog
else if(de_d[19])
    vout_data_r <= read_data;
// 不再 else 清零：消隐期间保持上一拍有效像素
```

- 从源头去掉每行第一个像素的 0；
- 不动 DE/HS/VS 时序，不引入行缓存/BRAM；
- 图片页、目录页黑线消失；
- 主菜单最左仍可能有 **1 px 级极细浅白线**（上一行右端像素的保持值），
  用户确认保留这一版，不再为此增加行缓存。

同时保留 v47 的 SPI 25 MHz（`spi_master` 的 `S_FAST`），读图/音频正常。

## 4. 资源 / 时序（v54）

| 项 | v47 | **v54** |
|---|---|---|
| LUT / REG | 17 288 / 6 375 | **17 219 / 6 368** |
| BRAM / DSP | 54 / 20 | **54 / 20** |
| mslices | 4 582 / 4 900 | **4 569 / 4 900（93.2%）** |
| Setup / Hold | +1079 / +25 ps | **+328 / +33 ps**（0 FEPS，seed 3） |
| bit / MD5 | `…_v47.bit` / `7330B46F…` | **`…_v54.bit` / `B6D54613…`** |

已用 `program_spi` 固化到配置 FLASH。
