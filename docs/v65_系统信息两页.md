# v65 系统信息两页

日期：2026-10-26

## 现象/需求

原 `sysinfo_panel.v` 只有 6 行：器件 / 输出 / 音频 / 存储 / 资源 / 版本，
内容偏“参数贴纸”，评委看不到运行状态和自检结果。

## 改法

`rtl/sysinfo_panel.v` 扩成两页，仍复用 `font_rom` 的现有中文字模和 ASCII，
**0 新增 BRAM**：

### 1/2 配置

| 标签 | 值 |
|---|---|
| 器件 | EG4S20BG256 |
| 输出 | 640X480P60 RGB |
| 音频 | 48KHZ 16BIT WAV |
| 存储 | TF FAT32 IMG16 |
| 资源 | LUT17K BRAM54 |
| 版本 | V54 20261026 |

### 2/2 运行/自检

| 标签 | 值 |
|---|---|
| 器件 | HX4S20C BOARD |
| 输出 | HDMI1.4B 25MHZ |
| 音频 | WAV5 48K VOL100 |
| 存储 | SD OK IMG16 WAV / SD ERR IMG16 WAV |
| 资源 | DSP20 MS4569 |
| 版本 | SELFTEST PASS / SELFTEST FAIL |

- 标题右侧显示 `1/2`、`2/2`；底部一行 `ENTER/ROT:NEXT  BACK:EXIT`。
- 打开默认第 1 页；**Enter 或旋转编码器翻页，Back 关闭**；离开主菜单强制关闭。
- 值表用一条 8 bit 扁平 case `{page,row,col}`（2×6×16），没有新增 BRAM；
  标题从 4 字扩到 8 字（128 px），底栏单独一个 25 字符窗口。
- `SD OK/ERR` 与 `SELFTEST PASS/FAIL` 由 `boot_ok` 驱动。

## 资源/时序

| 项 | v54 | **v65** |
|---|---|---|
| LUT / REG | 17 219 / 6 368 | **17 299 / 6 346** |
| BRAM / DSP | 54 / 20 | **54 / 20** |
| mslices | 4 569 / 4 900 | **4 595 / 4 900（93.8%）** |
| Setup / Hold | +328 / +33 ps | **+350 / +25 ps**（0 FEPS，seed 3） |
| bit / MD5 | `…_v54.bit` / `B6D54613…` | **`…_v65.bit` / `C451FF22…`** |

只比 v54 多 **26 mslices / 97 LUT**，BRAM 不变。已 `program_spi` 固化。

  “SD OK IMG16 WAV” 换成实际图片数/当前曲目。
