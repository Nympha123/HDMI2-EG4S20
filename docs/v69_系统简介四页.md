## 字库 / 编码

| ROM | 规模 | BRAM | 说明 |
|---|---|---|---|
| `rtl/sysintro_text.hex` | 1024 × 9 bit | 1（BRAM9K） | `addr = {page[1:0], line[1:0], slot[5:0]}`；`line0` slot0..4 = 页标题、slot8..11 = 标题字；`line1..3` = 正文 |
| `rtl/font_rom_sys.hex` | 128 槽 × 16 行 | 4 | 114 个 16×16 汉字/标点，微软雅黑 16 px，**字面位置固定、不做包围盒居中**（否则「、。，」会飘到格子中间） |

码值（9 bit）：

```
0x000..0x07F  ASCII（查主字库 font_rom，取 bit11..bit4 = 8 px 宽字心）
0x080 | n     汉字左半（查 font_rom_sys 槽 n，画 gx 0..7）
0x180 | n     汉字右半（同一槽 n，画 gx 8..15）
```

- `n` 就是 `font_rom_sys` 的槽号，RTL 里**没有任何硬编码字槽**，改文案不必改 Verilog。
- 主字库只补两个字：`0x1D 简`、`0x1E 介`（`tools/add_intro_title_glyphs.py`）；
  主菜单第三项 4 个字格 = 系 `0x90` / 统 `0x91` / 简 `0x1D` / 介 `0x1E`。
- `font_rom`、`font_rom_ext` 都不动，字幕/目录/设置/徽标逻辑一行没改。

## 流水

```
组合地址(taddr) -> 文本 ROM 输出 + 坐标寄存(第1拍) -> 字模 ROM 输出/字符选择(第2拍)
```

- 两拍与 `settings_panel` 一致，叠层不错位；
- ASCII 地址 = `{3'b000, code[6:0], 4'h0} + (15-row)`，汉字地址 = `{code[6:0], 15-row}`，
  两条路都在第 2 拍出数，选择靠 `cjk_s2`。

## 资源 / 时序

| 项 | v67 | **v69** |
|---|---|---|
| mslices | 4 620 / 4 900 | **4 538 / 4 900（92.6%）** |
| BRAM9K | 56 / 64 | **59 / 64（92.2%）** |
| LUT / REG | 17 427 / 6 363 | **17 113 / 6 376**（综合 16 766 / 6 206） |
| DSP | 20 / 29 | 20 / 29 |
| Setup / Hold | +499 / +25 ps | **+737 / +25 ps**（0 FEPS，place seed 2） |
| bit / MD5 | `…_v67.bit` / `34C1F8BD…` | **`HDMI2_HDMI14_Player_v69.bit` / `42076F1BECCB58E83C7A985369737046`** |

- 省资源的关键：正文改成 8 px 一格（以前 ASCII 也占 16 px 格），
  文本用 ROM 查表代替 v67 的 9 bit 扁平 `case`（原来一个 case 就要几百 LUT），
  所以 mslices 比 v67 少 82、BRAM 只多 3。
- BRAM 从 56 → 59：新小字库 4 块（v67 的小字库 2 块）+ 文本 ROM 1 块，净 +3。
- 时序：place seed 对结果影响很大（同一份 RTL）：seed 1 +262、**2 +737**（重影修好后）、3 −105（1 FEPS）、
  4 +125、5 +266、6 +128、7 +305 ps。最终用 **seed 2**，Hold 25 ps（fix_hold 必须开）。
- 修掉重影那版顺带把被截断的列号逻辑还原，Setup 余量从 +415 涨到 **+737 ps**、mslices 少 21。

## 自检（改版面/字库后先跑）

```powershell
python tools/make_sysintro_page.py        # 重排文本 + 字库 + 4 张预览
python tools/check_sysintro_render.py     # 先 lint 位宽，再用 RTL 的取址规则逐像素比对
# 期望：lint  : 位宽声明 OK
#       OK page 1..4: 0 diff pixels
```

`check_sysintro_render.py` 把 `sysinfo_panel.v` 的 taddr/code/gx/row/bit 规则在 Python 里
重放一遍，和生成器的理想版面对像素 —— 槽号、左右半、bit 抽取写错时它一定会报警，
而综合/布线不会（这类错误只会让屏上串位）。

### 上板后补的坑：标题/页标题「重影」

第一版上板后，「系统简介」和「四个展区」两处金色文字出现重影（一个字像叠了 2~4 份）。
根因在一行 Verilog：

```verilog
wire [1:0] tcol = tx[5:4], tgx3 = tx[3:0];   // tgx3 被一起声明成 2 bit
wire [2:0] hcol = hx[8:5], hgx3 = hx[4:1];   // hgx3 被一起声明成 3 bit
```

列号被截断成 0..3 / 0..7 循环，同一字的点阵在 16/32 px 格子里被重复铺了 4 份 / 2 份。
正文走的是 `{rom_q[8], xoff_s1}`，没受影响，所以只有两处金色标题坏。
修法：拆成独立声明。自检脚本里加了一条**静态 lint**（一条声明写多个名字且只有第一个带位宽 → FAIL），
这类错误综合、布线、像素比对全都发现不了。修好后 Setup 余量反而从 +415 涨到 **+737 ps**。
